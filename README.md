# Tic-Tac-Toe with AI
Welcome to an enhanced version of the classic Tic-Tac-Toe game, featuring a vibrant, modern UI and sophisticated AI gameplay. This project was developed as part of an Applied Artificial Intelligence course, showcasing both aesthetic design and intelligent gameplay mechanics.

## Features
### Modern Visual Design
- Vibrant Color Scheme : Features a dynamic color palette with deep blues, bright cyans, and striking orange accents
- Particle Effects : Enhanced visual feedback with dynamic particle animations
- Smooth Animations : Polished game feel with modern UI transitions
- Custom Game Shapes : Player can choose between triangles (orange-red) and diamonds (cyan)
### AI Implementation
The game features three distinct AI difficulty levels, each employing different algorithms:

- Easy Mode : Uses a probabilistic approach (70% random moves, 30% smart moves)
- Medium Mode : Implements minimax algorithm with depth limit 2
- Hard Mode : Utilizes advanced minimax algorithm with depth limit 4 for optimal gameplay
### Gameplay Features
- 4x4 Grid : Extended gameplay on a larger board for more strategic depth
- Score Tracking : Keeps track of player wins, AI wins, and ties
- User Customization : Input your name and choose your preferred game piece
- Interactive UI : Responsive buttons and hover effects for enhanced user experience
## Technical Implementation
- Built with Python and Pygame
- Implements alpha-beta pruning for efficient AI decision making
- Features modern UI components with shadow effects and rounded rectangles
## How to Play
1. Download the executable from the GitHub Repository
2. Run main.exe to start the game
3. Enter your name and select your preferred difficulty level
4. Enjoy the game with its vibrant new look!
