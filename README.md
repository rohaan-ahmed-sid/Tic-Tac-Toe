# Tic-Tac-Toe Game with AI
Welcome to the Tic-Tac-Toe game project, an exciting implementation that integrates Artificial Intelligence to enhance the classic game experience. This project was developed as part of an Applied Artificial Intelligence course.

## Features
- AI Integration : The game includes AI algorithms that adapt to different difficulty levels: Easy, Medium, and Hard.
- User-Friendly Interface : A simple and engaging frontend that makes the game accessible to everyone.
- Robust Backend : Ensures smooth and efficient gameplay.
## AI Algorithms
The AI component is the highlight of this project. It uses various algorithms to provide a challenging experience:

- Easy Level : Uses basic random moves.
- Medium Level : Implements a heuristic-based approach.
- Hard Level : Utilizes the Minimax algorithm for optimal play.

## How to Play
1. Download the executable from the GitHub Repository .
2. Run main.exe to start the game.
3. Choose your difficulty level and enjoy the game!
